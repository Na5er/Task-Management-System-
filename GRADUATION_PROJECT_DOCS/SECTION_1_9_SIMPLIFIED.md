# 1.9 Organization of Work Packages

## Overview

This graduation project is organized into **10 work packages (WP)**:
- **WP 1-5:** Graduation Project I (Foundation Phase)
- **WP 6-10:** Graduation Project II (Advanced Phase)

Since this is a **solo graduation project**, the student **Nasser** leads and completes all work packages individually with full responsibility and accountability.
